# DRONOTICZ

Welcome to **DRONOTICZ**, a website dedicated to showcasing the latest advancements in drone technology. This platform highlights how innovation and robotics converge to shape the future, revolutionizing industries and improving lives worldwide.

## About the Project

This project is a Single Page Application. It is a responsive website built using React and CSS, based on a (Figma design)[https://www.figma.com/design/MfpgDVuO84ynjmSGzCVpsO/Assignment-2?node-id=13-5&node-type=FRAME&t=sKFHA9H76qiTMgic-0]. The website emphasizes modern web development practices, utilizing Flexbox and the `position` property to create a dynamic and responsive layout.

## Features

- **Responsive Design:** The website is fully responsive, ensuring a seamless experience across various devices and screen sizes.
- **Flexbox Layout:** Flexbox is used extensively to create flexible and efficient layouts.
- **Position Property:** Strategic use of the `position` property enhances the design's responsiveness and layout control.

## Technologies Used

- **React:** A JavaScript library for building user interfaces.
- **CSS:** Styling is handled with CSS, focusing on Flexbox and `position` for layout management.
